# 秤心育兒指南：網站設計規格

**日期：** 2026-09-02

**專案英文名稱：** Libra Family Compass

**專案資料夾：** `libra-family-compass`

**產品類型：** 臺灣孕產與育兒補助決策工具

**平台：** Web、RWD、GitHub Pages

**技術：** HTML、CSS、原生 JavaScript、原生 ES Modules、`localStorage`

## 1. 產品目的

「秤心育兒指南」協助一個設籍臺北市、已有五歲以上兒子、並正迎接第二名新生女兒的家庭，將孕期注意事項、待產準備、補助資格、托育選擇及兩名子女的家庭支出放在同一個容易查找的網站中。

網站不是政府申辦系統，也不是醫療診斷工具。它的核心價值是把分散在中央與臺北市不同機關的規則，整理為有查核日期、有官方來源、能依家庭情境篩選的行動清單。任何補助結果均以主管機關審核為準，任何健康異常均應聯絡產檢院所或立即就醫。

## 2. 家庭情境與預設值

首版使用下列非敏感預設情境：

- 居住與設籍地區：臺北市。
- 第一名子女：兒子，五歲以上、未滿六歲。
- 第二名子女：女兒，於 2026-09-02 為孕期第 32 週。
- 托育情境：尚未決定，需比較自行照顧、公共托育、準公共托育人員與其他托育方式。
- 介面主題：預設酒紅色，可切換倫敦藍。

網站不預設或推算妻子的生日與女兒預產日期，以避免將「32 週」及「預計同生日、天秤座」之間可能存在的日期差異誤寫為確定資訊。使用者可在本機設定「孕週基準日＋孕週」或預產日期；若未設定預產日期，只顯示孕週與週次建議，不顯示倒數天數。

所有設定只保存在使用者裝置的 `localStorage`，不得要求或保存姓名、身分證字號、金融帳戶、電話、精確地址、醫療紀錄或其他敏感個人資料。

## 3. 成功標準

首版須符合以下結果：

1. 使用者進入首頁後十秒內能看見目前孕週、近期三項行動與兩名子女相關補助入口。
2. 使用者能在三次操作內找到特定補助的金額、基本資格、互斥條件、申請期限及官方來源。
3. 待產包勾選、家庭設定、主題及自訂花費在重新載入頁面後仍保留。
4. 無網路時，核心孕期、補助與清單內容仍可由已載入的靜態檔案閱讀；外部開放資料無法取得時顯示本機備援與更新日期。
5. 手機、平板及桌機皆不出現橫向捲動，主要互動可由鍵盤完成，文字及控制項達到 WCAG 2.2 AA 對比要求。
6. 專案無建構步驟即可由靜態 HTTP 伺服器執行，且所有內部路徑可在 GitHub Pages 的子路徑下正常運作。

## 4. 首版範圍

### 4.1 今日首頁

首頁採家庭任務儀表板，而非宣傳型 Hero：

- 顯示「第 32 週」或由使用者設定計算出的孕週。
- 顯示近期產檢、待產包進度及尚未處理的補助期限。
- 以「媽媽與女兒」、「五歲兒子」、「全家」三個入口整理資訊。
- 顯示資料基準日、來源狀態與醫療／資格免責說明。
- 提供主題切換、家庭設定與清除本機資料功能。

### 4.2 孕期照護

孕期內容依孕週分為初期、中期、後期與產後準備。首版重點放在第 32 週以後：

- 14 次公費產前檢查節點。
- 第 32 週後第三次一般超音波檢查提醒。
- 第 35 週至未達第 38 週產前乙型鏈球菌篩檢提醒。
- 胎動、落紅、規律陣痛、破水、陰道出血、持續腹痛等就醫提示。
- 待產醫院、交通、聯絡人及大寶照顧安排的非敏感準備項目。
- 產後出生登記、健保加保、健保卡與生育給付的一站式事項。

健康資訊以國民健康署資料為主。危險徵兆使用明顯但不驚嚇的警示區塊，固定顯示「若有不適或疑似產兆，請直接聯絡產檢院所；緊急情況撥 119」，不得使用網站計算結果延誤就醫。

### 4.3 待產包清單

清單分類如下：

- 證件與醫療資料。
- 媽媽住院用品。
- 女兒衣物與返家用品。
- 陪產者用品。
- 五歲兒子的照顧與交接。
- 出院與返家安全。

每一項包含標題、簡短說明、是否為院所可能提供、是否必帶與官方／院所確認提示。支援勾選、取消、自訂項目、分類進度、全部清除及列印。刪除自訂項目前需確認；清除全部資料前需說明影響範圍。

### 4.4 補助導覽

補助資料分為「孕期」、「生產」、「0 至未滿 2 歲」、「2 歲至入國小前」、「全家與租稅」及「特殊資格」六類。一般家庭首版至少納入：

- 孕婦 14 次公費產檢及指定檢查。
- 臺北市好孕 2U 孕婦乘車補助，包含 2026-10-01 調整前後的時間規則。
- 2026 年起各類社會保險生育給付加補助至每胎合計新臺幣 10 萬元的適用說明。
- 臺北市第二名新生兒生育獎勵金新臺幣 4.5 萬元、設籍條件與申請期限。
- 未滿二歲第二名子女育兒津貼每月新臺幣 6,000 元。
- 公共托育與準公共托育費用補助，以及第二名子女加碼。
- 臺北市友善托育補助與協力照顧補助，標示不可重複請領的組合。
- 二歲至未滿五歲育兒津貼。
- 五歲至入國民小學前第二名子女就學補助每月新臺幣 6,000 元；若就讀平價教保服務機構，改顯示家長月繳上限。
- 六歲以下幼兒學前特別扣除額：第一名子女每年新臺幣 15 萬元，第二名及以上子女每人每年新臺幣 22.5 萬元。
- 育有未成年子女家庭的中央擴大租金補貼加碼提示。
- 孕婦及育有六歲以下兒童者停車位識別證。

特殊資格區提供低收入戶、中低收入戶、弱勢家庭、原住民、身心障礙、早期療育及特殊境遇家庭的「可能適用」索引。未取得家庭條件前不得宣稱符合資格，僅顯示核對項目與主管機關入口。

每筆補助卡片必須顯示：

- 補助名稱與主管機關。
- 適用階段、地區、子女排序及照顧方式。
- 金額或計算方式；不適合單一數字時顯示範圍與條件。
- 必要資格與不適用情況。
- 與其他補助是否互斥。
- 申請時點、期限、方式與應備資料摘要。
- 官方來源連結、法規或公告生效日、最後查核日期。
- 「初步符合」、「需要確認」或「不符合目前設定」狀態；狀態不能只用顏色區分。

「所有補助」在首版定義為：收錄截至查核日可由中央及臺北市官方來源識別、且與一般孕產、未滿六歲育兒、托育、就學、租稅或住宅直接相關的主要方案，再提供特殊資格索引。網站不得保證涵蓋未公開、個案型、職業工會、雇主或特定院所自辦方案。

### 4.5 保母與托育比較

使用者選擇女兒排行、年齡、家庭資格及照顧方式後，顯示：

- 中央補助、臺北市加碼及估計自付額。
- 與育兒津貼是否互斥。
- 是否需為登記托育人員、公共化或準公共合作單位。
- 金額的生效日、資料查核日及官方說明。
- 查找臺北市公辦民營托嬰中心、評鑑結果與主管機關聯絡方式的入口。

估算結果只能標示「依目前設定試算」，不得標示為核定金額。使用者未填實際月費時，只顯示可申請補助，不推算自付額。

### 4.6 兩名子女花費簿

花費簿以生命階段整理，而非會計系統：

- 孕期與生產。
- 新生兒至未滿二歲。
- 二歲至入國小前。
- 入小學後的預備分類。

預設分類包含醫療、托育／教育、奶粉與飲食、尿布與耗材、衣物、交通、保險、活動與其他。使用者可輸入每月支出、一次性支出及實際補助；畫面顯示月支出、年化支出、補助合計與家庭淨支出。所有數字皆為本機估算，不蒐集所得或帳戶資料。

## 5. 資訊架構

主導覽包含六個區段：

1. `今日`：家庭儀表板與近期任務。
2. `孕期`：孕週時間軸、產檢及醫療警示。
3. `補助`：補助篩選、資格摘要與官方來源。
4. `待產包`：可保存與列印的清單。
5. `花費`：兩名子女生命階段支出與補助試算。
6. `資料來源`：官方來源、查核日期、開放資料狀態與免責說明。

首版採單頁應用式區段導覽，但保留原生錨點網址，例如 `#benefits`、`#hospital-bag`。不使用前端路由函式庫，避免 GitHub Pages 重新整理時出現 404。JavaScript 無法執行時，頁面仍顯示核心說明、來源及基本清單。

## 7. 資料模型與規則

### 7.1 家庭設定

```js
{
  region: 'taipei',
  referenceDate: '2026-09-02',
  pregnancyWeek: 32,
  pregnancyDay: 0,
  dueDate: null,
  children: [
    { id: 'older-son', order: 1, stage: 'age-5' },
    { id: 'baby-daughter', order: 2, stage: 'pregnancy' }
  ],
  careScenario: 'undecided',
  householdTags: []
}
```

若使用者提供預產日期，孕週以「預產日期減 280 天」為妊娠起算基準估算，並明確標示為方便整理的估算值；醫療院所判定優先。若只提供孕週基準，則以基準日差值前進或後退孕週。結果限制在 0 週 0 天至 42 週 0 天，超出時顯示需要重新確認設定。

### 7.2 補助紀錄

每筆補助使用一致欄位：

```js
{
  id: 'taipei-birth-award',
  title: '臺北市生育獎勵金',
  jurisdiction: 'taipei',
  stages: ['birth'],
  childOrders: [1, 2, 3],
  careModes: ['any'],
  amount: { kind: 'fixed', value: 45000, unit: 'per-birth', note: '第二名新生兒' },
  requirements: [],
  exclusions: [],
  application: { channels: [], documents: [], deadline: '' },
  source: {
    issuer: '臺北市政府',
    title: '',
    url: '',
    effectiveFrom: '2025-09-09',
    verifiedAt: '2026-09-02'
  },
  status: 'current',
  tags: []
}
```

金額欄位支援固定金額、每月金額、上限、依公式計算與文字說明。資格引擎僅根據使用者已提供的非敏感設定產生三態結果：`likely`、`check`、`not-match`。缺少必要條件時一律回傳 `check`，不擅自推定。

### 7.3 本機資料版本

`localStorage` 鍵使用 `libraFamilyCompass:v1:*` 命名。讀取時驗證型別與允許值；解析失敗或版本不符時使用安全預設值，保留可恢復提示，不讓整個頁面失效。清除資料僅刪除此前綴的鍵，不影響其他網站資料。

## 8. 官方資料與開放資料策略

核心政策規則採版本化靜態資料，原因是補助資格通常存在條件、互斥、公告生效日及例外，臺北市開放資料中的「育兒津貼」資料集主要是統計資料，不能代替法規或申辦說明。

首版官方基準來源包括：

- 國民健康署「孕婦產前檢查項目及補助金額」。
- 國民健康署「孕媽咪衛教手冊」與「孕婦健康手冊」。
- 我的 E 政府「安心懷孕及友善生養的措施與設施」。
- 勞動部勞工保險局 2026 年生育給付加給補助說明。
- 臺北市生育獎勵金發放辦法。
- 臺北市社會局好孕 2U、友善托育、協力照顧及兒童經濟補助資料。
- 臺北市教育局五歲幼兒就學補助與學前補助資料。
- 財政部幼兒學前特別扣除額說明。
- 內政部戶政司出生登記與跨機關通報服務。

開放資料只用於非資格判定功能：

- 臺北市公辦民營托嬰中心名單。
- 臺北市托嬰中心評鑑結果。
- 臺北市育兒津貼與托育服務統計摘要。

`open-data.js` 使用 `AbortController` 設定六秒逾時，驗證 HTTP 狀態及必要欄位。網路、CORS、逾時或資料格式錯誤時顯示「目前使用本機備援資料」，並顯示備援資料日期；核心補助內容不受影響。若實作驗證證明官方端點不允許 GitHub Pages 跨來源存取，首版直接使用有來源日期的靜態快照及官方資料集連結，不建立代理服務。

## 9. 視覺與互動方向

採用「日系家庭生活誌 × 公民資訊編輯設計」。視覺不使用制式化 SaaS 儀表板，也不模仿政府網站；以生活誌的呼吸感承載政務資訊的精準度。

### 9.1 色彩

酒紅主題：

- 深主色：`#4B1D2B`。
- 淺底色：`#F3E7E9`。

倫敦藍主題：

- 深主色：`#12323E`。
- 淺底色：`#E4ECEE`。
- 強調色：`#A66B4F`。

共用中性色：

最終實作須以自動與人工方式確認文字、按鈕、焦點環及狀態組合的 AA 對比，不因此規格中的候選色值而犧牲可讀性。

### 9.2 字體與排版

- 主要字體：`"Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif`。
- 不依賴外部字體 CDN；使用者裝置沒有 Noto Sans TC 時採系統字體。
- 標題採較窄字寬、適度字距與明確層級，不使用仿手寫字體承載內文。
- 內文字級最小 16px，主要閱讀行高至少 1.7，單行寬度控制於約 68 個中文字元以內。

### 9.3 元件語言

- 卡片使用 0 至 12px 小圓角、細邊線與色塊切面，不使用大面積陰影。
- 狀態圖示採自行建立的簡潔 SVG 線條，不使用 Emoji。
- 天秤意象只出現在品牌圖章、分隔線或進度刻度，避免星座主題壓過孕產資訊。
- 數字金額使用等寬數字特性，單位與條件緊鄰金額。
- 桌機採 12 欄編輯格線；手機改為單欄閱讀，重要任務先於統計內容。

### 9.4 動畫原則

- 動畫只用於區段切換、進度更新與主題過渡，時間介於 120 至 220 毫秒。
- 不使用視差、浮動裝飾、循環呼吸光、數字滾動或阻礙閱讀的進場動畫。
- `prefers-reduced-motion: reduce` 時取消非必要動畫與平滑捲動。

## 10. RWD 與無障礙

斷點：

- 手機：小於 `640px`。
- 平板：`640px` 至 `1023px`。
- 桌機：`1024px` 以上。

無障礙要求：

- 提供跳至主要內容連結、正確標題階層、地標與表單標籤。
- 所有操作均可由鍵盤完成，焦點順序符合閱讀順序，焦點環清楚可見。
- 互斥補助、警示與完成狀態同時使用文字、圖示及顏色。
- 清單進度更新使用節制的 `aria-live="polite"`。
- 對話框若使用原生 `<dialog>`，須處理焦點返回；不支援時提供頁內確認區塊。
- 觸控目標至少 44×44 CSS 像素。
- 表格在手機改為有標題的資料列，不靠橫向捲動閱讀主要內容。

## 11. 錯誤、空白與邊界情況

- 孕週設定缺失：顯示第 32 週預設情境與「更新設定」提示。
- 預產日期無效或超出合理範圍：不儲存，行內說明可接受格式。
- 沒有符合的補助：保留目前篩選摘要，提供放寬篩選及查看特殊資格索引。
- 金額無法單一估算：顯示計算規則與需要確認的欄位，不以零元代替未知。
- 外部資料失敗：切換本機備援並顯示原因及日期，不重複彈出錯誤。
- `localStorage` 被停用或額度不足：本次操作仍有效，顯示「此裝置無法保存變更」。
- 舊資料結構：以版本化遷移或安全預設復原，不執行任意字串內容。
- 來源超過 120 天未查核：顯示「建議重新確認」標記；即使金額看似相同也不可隱藏。

- `404.html` 提供返回首頁的相對連結，不進行無限重新導向。

- 以本機靜態伺服器開啟首頁，檢查控制台錯誤與主要網路請求。

- 僅用鍵盤走過主導覽、篩選、清單、主題與清除流程。

## 16. Git 工作方式

1. 在 `libra-family-compass` 初始化 `main` 分支。
2. 本設計規格作為初始提交，提交訊息為 `docs: 建立秤心育兒指南設計規格`。
3. 建立 `feature/initial-site` 分支執行功能工作；不直接在 `main` 撰寫功能程式碼。
4. 實作計畫依可獨立測試的里程碑提交，描述使用繁體中文。
5. 完整測試、程式碼審查與修正後，依 `finishing-a-development-branch` 流程讓使用者決定本機合併、推送建立 PR 或保留分支。
6. 執行任何 `git push` 前，先顯示 remote、branch 與完整待推送 commit 清單並取得授權。
