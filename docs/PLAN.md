# 秤心育兒指南：產品與實作計畫

## 需求

建立一個可直接於瀏覽器執行、可部署至 GitHub Pages 的臺灣孕產與育兒補助資訊網站。首版服務臺北市一家四口：五歲以上哥哥、於 2026-09-02 為第 32 週的孕婦，以及即將出生的第二名女兒。核心內容包含孕期注意事項、待產包、中央與臺北市補助、可能的保母／托育選擇、兩名子女不同年齡的花費與補助。

產品名稱為 Libra Family Compass，中文名稱為「秤心育兒指南」，類型為「臺灣孕產與育兒補助決策工具」。預設酒紅色，可切換倫敦藍；使用 HTML、CSS、原生 JavaScript、ES Modules 與 `localStorage`。

## 範圍

### 首版包含

- 孕週基準／預產日期設定、14 次公費產檢、後期檢查與緊急就醫提示。
- 六分類 48 項待產包、自訂項目、進度、清除與列印。
- 18 項一般家庭主要方案與特殊資格索引，包含官方來源、條件、限制、申請方式及非正式資格狀態。
- 第二名女兒的自行照顧、公共、準公共及非準公共托育補助比較入口。
- 五歲以上哥哥的就學補助、平價教保月繳上限與六歲以下租稅扣除額。
- 家庭每月／一次性花費與實際補助試算。
- 臺北市 29 處公辦民營托嬰中心公開資料快照與官方資料集連結。
- 雙主題、RWD、SEO、無障礙基礎、離線可讀核心內容與本機保存。

### 首版不包含

- 政府帳號登入、線上申辦、資格核定或自動送件。
- 後端、雲端同步、定位、地圖、即時空位、推播或個資保存。
- 醫療診斷、預產日期推論、所得稅額計算或保母媒合。
- 雇主、職業工會、特定醫院、商業保險或未公開個案補助的完整清單。

## 里程碑

1. 產品與視覺規格：完成並核准。
2. 零相依專案與測試基礎：完成。
3. 孕週、補助、待產包、花費與本機狀態領域模組：完成並具單元測試。
4. 酒紅／倫敦藍 RWD 介面：完成並通過靜態結構測試。
5. 表單、篩選、清單、保存及安全文字渲染：完成並經瀏覽器操作驗證。
6. 臺北市托育公開資料：完成 API／CSV 介面、跨來源調查與 29 筆日期快照。
7. GitHub Pages、SEO、文件及發布驗證：完成後才進入程式碼審查與分支收尾。

## 工作分解

- 資料層：孕期、補助、待產包與托育機構皆為獨立 ES Module，記錄來源及查核日。
- 領域層：計算孕週、篩選補助、產生提示、彙整花費、處理開放資料格式。
- 狀態層：以不可變狀態物件協調介面，只透過具版本前綴的 `localStorage` 保存。
- 呈現層：以語意 HTML 與安全 DOM API 建立卡片、清單、狀態與資料來源。
- 樣式層：設計 token、基礎排版、元件與三組 RWD 檔案分離。
- 品質層：Node.js 內建測試、內容驗證、Git 差異檢查及真實瀏覽器流程。

## 風險

- 政策變動：每筆資料顯示查核日及官方來源；內容維護需重新跑來源驗證。
- 資格誤判：只提供「初步符合／需要確認／目前不符」，不收集足以正式核定的敏感條件。
- 醫療風險：固定顯示聯絡院所與 119 提示，不以孕週計算延後就醫。
- 開放資料不可用：核心政策不依賴 API；端點被 CORS 阻擋時顯示完整有日期快照。
- 本機資料遺失：捕捉儲存錯誤並說明 `localStorage` 不同步、可能被瀏覽器清除。
- GitHub Pages 子路徑：所有本機資源採相對路徑，測試禁止根目錄資源路徑。

## 驗收條件

- 開啟首頁可看到有效孕週、近期節點、補助、待產包、花費與來源六大內容。
- 依第二名子女與托育方式篩選後，金額與判讀文字一致，且可回到官方來源。
- 主題、孕週設定、待產包及花費在重新載入後保留；清除操作需要確認。
- 自訂文字不會被解析為 HTML。
- 320px 以上手機、平板與桌機無橫向內容溢位，鍵盤可操作主要控制項。
- 無網路時核心靜態內容仍可閱讀；托育名單準確標示備援模式及日期。
- `npm test`、`npm run validate` 與 `git diff --check` 全部成功。
- GitHub Pages 的 canonical、manifest、robots、sitemap、404 與相對資源路徑齊備。
