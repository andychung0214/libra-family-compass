# 秤心育兒指南：視覺方向

## 可選風格

1. **家庭健康手冊 × 生活誌（首版採用）**：以醫療手冊的欄線、索引與查核感承接可信度，再加入家庭雜誌的留白與溫度。適合資訊密度高、需要長期使用的孕產題材。
2. **安靜臨床**：大量白色、冷灰與清楚表格，專業度高，但較難呈現一家四口的情感連結。
3. **日系紙品／手帳**：仿紙張、標籤與手寫筆記較親切，但過多裝飾會降低政策資訊辨識速度。
4. **當代公民服務**：高對比、粗體、模組化資料面板，效率佳，但容易接近一般政府入口網站。

首版套用「家庭健康手冊 × 生活誌」，再以日式極簡及侘寂的克制方式處理：可見欄線、偏暖紙色、不追求完美對稱、不使用制式漸層 Hero 或大量浮動卡片。代表性視覺是「家庭平衡刻度」：媽媽、哥哥、女兒並列在同一條細線上，每個節點有清楚角色與目前任務。

## 字體策略

- 標題：系統可用的繁體中文字體優先，字重 650–760，緊湊字距，避免裝飾型襯線字造成醫療資訊不易讀。
- 內文：`system-ui`、`Noto Sans TC`、`PingFang TC`、`Microsoft JhengHei` 後備；基準 16px 以上、行高約 1.72。
- 數字與資料標籤：系統等寬字體堆疊，提升金額、日期、孕週與索引掃讀效率。
- 不載入第三方 Web Font，避免阻塞、追蹤與離線落差。

## 元件規格

- 按鈕與表單控制項：最小高度 44px；焦點框 3px 且有外距。
- 頁首：細資訊列、品牌、水平章節索引、主題按鈕；手機可水平捲動導覽但頁面本體不溢位。
- 任務卡：頂部 3px 主題線、方正低圓角、無陰影，使用編號與標題建立層級。
- 補助卡：狀態、主管層級、名稱、金額、摘要、標籤、可展開條件、查核日與官方連結完整呈現。
- 健康警示：左／上方警示線與明確文字，不使用閃爍或聳動紅色滿版。
- 清單：原生核取方塊、可點標籤、完成刪除線；必帶與問院所以文字膠囊標記。
- 花費摘要：2×2 資料格，手機改單欄；所有金額明確以 `NT$` 顯示。
- 來源卡：頂部細線、機關、官方標題及查核日期；外部連結另開分頁並使用安全 `rel`。

## RWD 規則

- 手機：`≤639px`，所有主要內容單欄，家庭刻度轉為直向，花費與機構名單單欄。
- 平板：`640–1023px`，主要內容單欄、表單與來源多為雙欄，待產進度取消黏附。
- 桌機：`≥1024px`，最大內容寬 1180px，孕期／待產／花費使用不對稱雙欄。
- 支援最小寬度 320px；導覽自身可橫向捲動，不可造成文件橫向捲動。

## 動畫原則

- 只使用 120–220ms 的顏色、邊框、位移與進度寬度過場。
- 動畫只用於回應操作，不自動輪播、不使用視差、不循環吸引注意。
- `prefers-reduced-motion: reduce` 時取消平滑捲動並把動畫時間降至近乎零。

## 禁止事項

- 禁止漸層背景、玻璃擬態、霓虹光、過量陰影及漂浮膠囊堆疊。
- 禁止通用 AI 生成家庭照、過度完美的 3D 寶寶角色與醫療器官插畫。
- 禁止大面積置中宣傳 Hero、空泛口號與每區相同三張卡片的制式排版。
- 禁止粉紅等於女兒、藍色等於兒子的刻板性別配色。
- 禁止用顏色單獨傳達資格或風險；禁止用動畫延遲緊急資訊。
- 禁止小於 44px 的主要點擊區、低對比灰字、全大寫長段落與橫向內容溢位。
