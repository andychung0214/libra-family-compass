## 行動裝置與 RWD

測試 320×568、375×812、768×1024、1024×768 及 1440×900：

- [x] 375px 寬度的主要網格為單欄，文件無橫向內容溢位。
- [x] 320px 寬度主要內容無橫向溢位，頁首導覽維持在自身區域。
- [x] 768px 平板主區單欄、補助與機構名單雙欄，文件無橫向溢位。
- [x] 1440px 桌機主區與資料卡依規格分欄，文件無橫向溢位。
- [ ] 觸控區至少 44×44px，核取方塊與標籤容易點選。
- [ ] 旋轉裝置後不遺失輸入與進度。

## 無障礙

- [x] 頁面具有跳至主要內容、banner、navigation、main、region、complementary 與 contentinfo 地標。
- [x] 所有表單欄位有可辨識標籤，動態數量與狀態使用即時區域。
- [ ] 只用鍵盤完成主題、設定、篩選、清單、花費及展開內容。
- [ ] Tab 順序符合閱讀順序，焦點永遠可見且不被黏附頁首遮住。
- [ ] 200% 與 400% 放大不遺失內容或功能。
- [x] 酒紅、倫敦藍的主要文字、控制項、焦點與狀態色對比達 WCAG 2.2 AA。
- [ ] 作業系統減少動態效果時無平滑捲動或顯著過場。
- [ ] 使用 NVDA 或 VoiceOver 檢查補助狀態、清單名稱與錯誤訊息。

## 離線與錯誤情境

- [x] 官方端點跨來源不可用時，顯示 `fallback`、資料檔日期及完整 29 筆快照，核心內容正常。
- [ ] 瀏覽器拒絕 `localStorage` 時，頁面仍可使用並讀出保存失敗訊息。
- [ ] 模擬網路中斷後重新載入；已載入的靜態檔案由瀏覽器快取行為決定，未安裝 Service Worker 時不宣稱完整離線安裝。
- [ ] 404 頁可用鍵盤返回首頁，沒有重新導向迴圈。
