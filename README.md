# 秤心育兒指南

Libra Family Compass 是一個可直接部署至 GitHub Pages 的臺灣孕產與育兒補助決策工具。首版以臺北市一家四口的情境為核心：媽媽於 2026-09-02 為孕期第 32 週、哥哥五歲以上，家中正迎接第二名女兒並比較後續托育方式。

網站把孕期節點、待產包、中央與臺北市補助、托育機構公開名單，以及兩名子女家庭花費整理在同一頁。本站不是政府或醫療機構；補助仍以主管機關審核為準，孕期不適應直接聯絡產檢院所。

## 遊戲介紹

本專案不是遊戲。此標題保留以對應交付清單中的欄位；實際產品是一個以家庭任務清單為核心的互動資訊網站，不含得分、勝負或抽獎機制。

## 特色

- 依基準日與孕週，或依預產日期，估算目前孕週並提示近期公費產檢節點。
- 整理中央與臺北市 18 項主要孕產、托育、就學、租稅與住宅方案，每筆均附官方來源及 2026-09-03 查核日期。
- 依孩子階段、子女排序及照顧方式顯示「初步符合／需要確認／目前不符」，但不取代正式審核。
- 30 項六分類待產包，特別納入五歲哥哥的照顧交接；支援自訂項目、進度、列印與本機保存。
- 家庭花費試算可區分媽媽、哥哥、女兒與全家，彙整每月及年化支出與實際補助。
- 完整列出臺北市 29 處公辦民營托嬰中心的官方公開資料快照及來源狀態。
- 酒紅色與倫敦藍雙主題；手機、平板、桌機三組 RWD 排版。
- 全站使用 HTML、CSS、原生 JavaScript 及 ES Modules，無第三方執行期套件、無建構步驟。

## 操作方式

1. 在「今日」檢視孕週與近期任務；需要時展開家庭設定，更新預產日期或孕週基準。
2. 在「補助」輸入關鍵字，並選擇孩子階段、子女排序與照顧方式。展開卡片核對資格、限制、期限及申請管道。
3. 在「待產包」逐項勾選，或加入自己的用品；勾選及自訂項目只保存在目前瀏覽器。
4. 在「花費」輸入支出與已確認的實際補助，檢視每月及年化淨支出。
5. 以頁首按鈕切換酒紅色或倫敦藍主題；在頁尾可清除本站於此裝置保存的資料。

不要在自訂清單或花費名稱中輸入姓名、身分證字號、帳戶、電話、地址、病歷或其他敏感個人資料。

## 安裝與執行

一般瀏覽不需安裝套件。為避免瀏覽器限制 ES Modules，請使用 Node.js 20 以上啟動隨附的靜態伺服器：

```powershell
git clone https://github.com/andychung0214/libra-family-compass.git
Set-Location libra-family-compass
npm run serve
```

接著開啟 `http://127.0.0.1:4173/`。若該連接埠已被使用，可指定其他連接埠：

```powershell
node scripts/serve.mjs 4287
```

也可使用任何能正確提供靜態檔案與 ES Modules MIME 類型的 HTTP 伺服器。

```text

│  ├─ eligibility.js            # 補助篩選與非正式資格提示
│  ├─ open-data.js              # 開放資料格式、逾時與備援介面
│  ├─ pregnancy.js              # 孕週與近期節點計算
│  ├─ costs.js                  # 家庭花費計算

├─ tests/                       # Node.js 內建測試執行器測試
├─ scripts/                     # 靜態伺服器與內容驗證
└─ docs/                        # 計畫、視覺方向與測試計畫
```

## 測試方式

```powershell
npm test
npm run validate
```

`npm test` 執行領域規則、資料結構、狀態、開放資料介面、渲染與靜態交付測試。`npm run validate` 另檢查每筆補助的來源欄位、必要交付檔案、首頁本機連結及 GitHub Pages 子路徑相容性。完整手動檢查清單見 [`docs/TEST-PLAN.md`](docs/TEST-PLAN.md)。

## 靜態網站

預定 GitHub Pages 網址：<https://andychung0214.github.io/libra-family-compass/>

部署方式：

1. 將通過測試的分支合併至預設分支並推送。
2. 在 GitHub 儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch**。
3. 選擇 `main` 與根目錄 `/ (root)` 後保存。
4. 等待部署完成，再以無痕視窗確認首頁、404、資源路徑與重新載入行為。

所有站內資源採相對路徑，可在 `/libra-family-compass/` 子路徑運作，不需要建構產物或後端服務。

## 已知限制

- 補助規則可能在查核後變動；本版內容查核日期為 2026-09-03，申請前須開啟卡片內的官方來源確認。
- 「所有補助」指首版已能由中央與臺北市官方來源辨識、且與一般孕產及未滿六歲家庭直接相關的主要方案，不包含雇主、工會、特定院所或未公開個案方案。
- 資格提示只使用地區、階段、子女排序與照顧方式，不蒐集所得、設籍期間或特殊身分，因此不能代替機關核定。
- 臺北市資料大平臺 API 的跨來源標頭不允許 GitHub Pages 直接讀取；網站使用完整日期快照並提供官方連結，不顯示即時空位。
- `localStorage` 可能因無痕模式、裝置政策或清除網站資料而失效；本機資料不會跨裝置同步。
- 孕週為日曆估算，不是醫療判斷；實際產檢與生產安排以醫療人員為準。
